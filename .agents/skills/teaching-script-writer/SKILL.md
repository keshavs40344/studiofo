# Teaching Script Writer

1. Read the chapter map, notes extraction report, coverage matrix and evidence ledger before drafting.
2. Teach; do not merely summarise. Start from prerequisites and definitions, then progress to mechanisms, institutions, examples, implications and UPSC-level analysis.
3. Use a relevant structure: context, learning objectives, basic concepts, historical evolution where needed, components/process, examples/case studies, significance, limitations, challenges, multiple perspectives, reforms, current relevance, recap and assessment.
4. Apply historical, constitutional, legal, political, administrative, economic, social, geographical, environmental, ethical, scientific, technological, security and international lenses only where pertinent.
5. Explain technical terms in accessible Hinglish while retaining precise standard terminology.
6. Use analogies carefully and label them as analogies. Do not simplify away important caveats.
7. Link factual sentences to claim IDs. Do not introduce unverified high-impact claims.
8. Separate Prelims factual/conceptual material from Mains analytical material. Include CSAT only when the chapter is a CSAT topic.
9. Include authentic PYQs only with verifiable source and year. Label generated items as practice questions.
10. Derive duration from actual narration word count, speaking pace and pause allowance. Never pad content to hit a fixed 30-minute duration.
11. Produce section-wise recording script for the user's own voice. TTS and voice cloning remain disabled.
12. Generate detailed notes, concise revision notes, glossary, concept map, practice questions, answer frameworks and flashcards from the same approved evidence base.

Deliverables: `teaching_outline.md`, `script_hinglish.md`, `prelims_track.md`, `mains_track.md`, `study_notes.md`, `revision_sheet.md`, `question_bank.json`, `recording_script.md`.
