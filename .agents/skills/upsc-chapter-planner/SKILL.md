# UPSC Chapter Planner

1. Determine the user's exact chapter/topic and any supplied notes. If absent, ask only for the missing chapter/topic.
2. Use the current official UPSC syllabus document for the applicable exam cycle. Store its source, date and version; do not rely on memory for the latest syllabus wording.
3. Map to Prelims GS-I, Prelims CSAT Paper-II, Mains GS-I, GS-II, GS-III and GS-IV. Keep CSAT separate from Mains GS-II. Keep Essay and optional subjects separate.
4. Identify direct syllabus links, prerequisite concepts and useful cross-paper connections.
5. Build learning objectives from foundational understanding to UPSC-level application.
6. Compare the supplied notes with every relevant subtopic. Keyword presence alone is insufficient; assess explanatory depth.
7. Mark each item COVERED, PARTIAL, MISSING, NOT_APPLICABLE or NEEDS_REVIEW. Record the reason and evidence.
8. Produce a chapter outline and an explicit coverage matrix before script drafting.
9. Do not expand the chapter with irrelevant dimensions merely to increase length. Explain why a likely relevant dimension is omitted.
10. Save structured output and retain source/page references to uploaded material.

Deliverables: `chapter_map.json`, `coverage_matrix.json`, `learning_objectives.md`, `chapter_outline.md`.
