# Visual Storyboard Director

1. Read the approved script, learning objectives, claim ledger and chapter coverage matrix.
2. Split content into scenes by concept and teaching purpose, not arbitrary fixed intervals.
3. For each scene record scene ID, section, learning objective, narration segment, claim IDs, duration estimate, visual type, asset requirements, on-screen text, layout, animation, transition in/out, audio cue, citations and approval state.
4. Select visuals that explain the concept. Use documentary footage only when it depicts the actual subject; otherwise prefer original diagrams, charts, maps or neutral contextual visuals.
5. Use maps for location, spatial distribution, routes, geography and geopolitics; validate boundaries, labels, date and map source.
6. Use charts only from supplied or verified datasets; store units, reference period, source, methodology and calculation checks.
7. Use flowcharts/process animation for systems, institutions, constitutional mechanisms, economic cycles and cause-effect relationships.
8. Create original SVG/HTML/vector graphics where possible. Keep Hindi font rendering and safe margins verified.
9. Choose animation only when it reveals, compares, sequences, highlights or clarifies information. Do not animate every object or force constant movement.
10. Choose transitions to express logical continuity; default to clean cuts, restrained dissolves, section cards, visual matches and purposeful map/timeline moves.
11. Keep complex diagrams on screen long enough for comprehension. Avoid unreadable walls of text and decorative B-roll.
12. Record asset origin and usage rights. Unverified external assets cannot enter an approved final export.
13. Include a low-resource fallback: still image with motion, SVG, simple vector animation, or clean teaching slide.

Deliverables: `storyboard.json`, `visual_asset_requests.json`, `graphics_spec.json`, `transition_plan.json`, `visual_qa_checklist.md`.
